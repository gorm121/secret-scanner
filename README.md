# Secret Scanner (Go)

Консольная утилита статического анализа для автоматического поиска случайно утекших секретов, приватных ключей и API-токенов в файлах исходного кода.

---

## Возможности

* **Рекурсивное сканирование**: обход дерева каталогов через `filepath.WalkDir`.
* **Автоматический пропуск бинарных файлов**: проверка первых 512 байт файла на нулевой байт (`0x00`), что исключает ложные срабатывания и зависания на скомпилированных бинарниках и медиафайлах.
* **Игнорирование служебных директорий**: автоматический пропуск `.git`, `.idea`, `node_modules`.
* **Защита от длинных строк**: использование `bufio.Scanner` с настраиваемым буфером до 10 МБ для предотвращения ошибок `bufio.ErrTooLong` на минифицированных файлах (например, сгенерированных бандлах).
* **Безопасное маскирование секретов**: функция `maskSecret` заменяет середину найденного токена звёздочками (`*`), оставляя только граничные символы, чтобы не светить секреты в выводе консоли и логах CI/CD.

---

## Встроенные правила обнаружения

На текущий момент в утилиту заложены правила поиска:
1. **`tg-bot-token`** — токены Telegram Bot API (формат `0123456789:AA...`).
2. **`private-key`** — заголовки приватных ключей RSA, DSA, EC, OPENSSH и PGP.

Движок правил легко расширяется добавлением новых структур `Rule` с произвольными регулярными выражениями.

## Установка и сборка

Требуется **Go 1.22+**.

```bash
git clone https://github.com/gorm121/secret-scanner.git
cd secret-scanner
go build -o secret-scanner.exe .
```

---

## Использование

Запуск сканирования директории с проектом:

```bash
.\secret-scanner.exe -path "C:\path\to\your\project"
```

### Пример вывода:

```text
RuleID: tg-bot-token
Severity: WARNING
FilePath: C:\path\to\your\project\config.go
Line: 14
Match: 7123****_XYZ

RuleID: private-key
Severity: WARNING
FilePath: C:\path\to\your\project\certs\id_rsa
Line: 1
Match: -----BEGIN RSA PRIVATE KEY-----
```
